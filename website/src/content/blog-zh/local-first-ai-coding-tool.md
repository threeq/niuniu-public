**摘要**：AI 编程工具挑花眼，但有一条硬线绕不开——**你的代码能不能不上别人的云**。做公司内部项目、外包客户代码、金融/政企合规系统时，「把整个仓库喂给云端服务」光过审就够呛。本文拆解**本地 AI 编码工具**该怎么选，并用[牛牛（niu6ai）](https://www.niu6ai.com)演示如何做到**代码不上云、还能多 agent 并行**。

## 为什么「代码不上云」是一条硬线？

「代码上云」的顾虑，拆开是三件具体的事：

1. **源码外泄** — 核心仓库被传到第三方服务器，哪怕承诺不训练，你也无法验证。
2. **凭证与密钥** — `.env`、私钥、内部 API token 跟着上下文一起被读走。
3. **合规审计** — 金融、政企、外包场景下，「数据出域」本身就违规，跟泄不泄露无关。

可大多数 AI 编程工具的默认形态恰恰是「重云端」的——代码、上下文、甚至历史记录都躺在别人服务器上。理想的**本地 AI 编码工具**应该是这样：**AI 算力可以走外部模型 API（这部分除非自建大模型否则无法本地化），但代码、工作目录、任务数据、历史记录全部留在本地。** 模型只看到当前任务需要的那段上下文，而不是你把整个硬盘交出去。

## 本地优先的 AI 编码工具「本地」在哪？

牛牛的定位正好对上这条线：**目标驱动的本地优先 AI 工作平台**。它「本地」在两个层面：

### 个人版：一个桌面 app，全在本机

个人版就是一个三平台桌面应用（macOS / Windows / Linux），启动后浏览器打开本机地址，**无需登录账号**：

- 你的**仓库、worktree、workspace、issue 看板**全在本机文件系统里；
- agent 是你本机的 `claude` / `codex` CLI 子进程，牛牛只是把它的输入输出桥接到浏览器；
- 唯一出网的是**模型 API 调用**——而且端点你说了算：走 Claude 官方，或换成智谱 / 通义 / DeepSeek / Kimi 等任意兼容端点。

换句话说：**牛牛本身不是云服务，而是一个跑在你电脑上的本地编排器。**

### 团队版：自部署，数据不出内网

团队场景下，牛牛提供**自部署**形态——在自己的服务器（甚至内网离线机器）上跑：

- 底层是 `niuniu-server` 进程 + 一个 **PostgreSQL** 数据库 + 反向代理；
- 两种装法：**Docker Compose**（一条命令拉起完整栈）或**裸机 + systemd**（适合已有 PG、麒麟/统信等无 Docker 的信创环境）；
- 支持组织、成员角色、**审计**、MFA。数据全在你自己的 PostgreSQL 里，备份就是一句 `pg_dump`。

## 动手搭：个人版 4 步跑通

1. **下载** — 到 [GitHub Releases](https://github.com/threeq/niuniu/releases/latest) 下对应平台的包，双击启动，浏览器自动打开本机页面，个人版直接进、不用注册。
2. **装系统依赖** — 需要 Node.js（v20+ LTS）、Git（2.30+）、以及 Claude Code 或 Codex CLI（二选一）；「设置 → 系统依赖」里每项都显示状态、版本、路径，缺的可一键装。注意 CLI 依赖 Node，**先装 Node 再装 Claude Code / Codex**。
3. **接模型（本地优先的关键选择）** — 已有 Claude Pro/Max 订阅就 OAuth 登录，凭证存本机；想完全自主可控就在「设置 → 环境变量」选预设、填三方平台 API Key（智谱 / 通义 / DeepSeek / Kimi 等），端点和模型名都预置好，**无需登录**。妙处在于：**算力可以挑供应商，代码始终不动窝**，甚至能接自己内网的兼容端点，做到几乎全链路不出域。
4. **新建 workspace，发个 hello** — 选仓库 → 牛牛自动基于默认分支拉一个 worktree → 启动 Agent → 输入 `hello`，收到回复即跑通。

## 本地优先，到底牺牲了什么、赚到了什么？

对比「云端 SaaS 式 AI 编程工具」和「牛牛本地优先」跑同一批日常任务的体感账本：

| 维度 | 云端 SaaS 工具 | 牛牛（本地优先） |
|---|---|---|
| 源码所在位置 | 上传到第三方服务器 | **始终在本机 / 内网** |
| 出网内容 | 代码 + 上下文 + 历史 | **仅当前任务的模型请求** |
| 模型供应商 | 平台锁定 | **任意端点可换**（官方 / 三方 / 内网） |
| 离线/信创环境 | 基本不可用 | **裸机自部署可用**（麒麟/统信/无 Docker） |
| 多任务并行 | 受会话限制 | **多 workspace 并行**，worktree 隔离 |
| 数据备份/审计 | 依赖平台 | **自有 PostgreSQL，`pg_dump` 即备份** |

「牺牲」的部分很诚实：**模型推理这一步仍要联网调 API**（除非自建大模型），这是所有非自建模型方案的共同前提。但除此之外，**代码、任务、历史、凭证全都没离开过你的机器**。赚到的，是一套既能多 agent 并行、又能过合规审计的工作流——对外包、金融、政企这些「代码不能上云」的场景，这往往是**能不能用上 AI 编程**的分水岭。

## 常见问题（FAQ）

**Q：本地 AI 编码工具是不是完全不联网？**
不是。代码、任务、历史都在本地，唯一出网的是模型推理请求——这一步除非自建大模型否则无法避免。区别在于出网的只是「当前任务需要的上下文」，而不是整个仓库。

**Q：代码不上云，还能用多个 AI agent 并行吗？**
可以。牛牛给每个 workspace 一个独立 git worktree + 独立 agent 会话，多个任务本地并行、互不干扰，本地优先和并行多开并不冲突。

**Q：内网离线、信创环境能用吗？**
能。团队版支持裸机 + systemd 自部署，适配麒麟/统信等无 Docker 环境，数据落在自有 PostgreSQL，不出内网。

**Q：模型供应商会被锁定吗？**
不会。可按 workspace 切换 Claude 官方 / 智谱 / 通义 / DeepSeek / Kimi 等任意兼容端点，也能接自己内网的端点。
